👥 Who does what

Each account type has its owner. New requests are assigned per person, per account, using these. To split work, add a share, e.g. Sean 70, Laurette 30. Names must match Settings → IT Staff.

📧 Who gets the account details

When IT (or the Perigee support admin) clicks Send account details, the logins are emailed to everyone below. The Perigee support admin is also copied on every new request. To let her record account info in this queue herself, give her a login with the Perigee Support Admin role. Separate several addresses with commas.

⏰ Reminders of open requests

Every weekday at 07:00, each IT tech is emailed the open tickets and new-starter requests assigned to them (Open or In Progress). Techs need an email in Settings → IT Staff. Anything unassigned goes to the address(es) below.

🔄 Microsoft 365 user list (for cross-checks)

Synced from Microsoft every night at 03:00, so requests can be checked for taken emails, existing accounts and duplicates.
